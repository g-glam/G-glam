حفظ شركة التوصيل
سيتم ربط الاختيار بمتجرك الحالي باستخدام Firebase Authentication UID.
ملاحظة أمنية:
مفاتيح API الحقيقية لا يجب الاعتماد عليها من JavaScript في المتصفح. الإرسال الفعلي للشحنات إلى EcoTrack أو Yalidine أو ZR أو Maystro يجب أن يتم من خلال Firebase Cloud Functions / Backend.

هذه الصفحة مسؤولة عن إعداد وربط الشركة بمتجرك فقط.
